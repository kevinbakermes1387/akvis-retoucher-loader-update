## Overview

AKVIS Retoucher Loader is a Windows-based tool for coordinating the preparation and launch of the AKVIS Retoucher workflow. It checks for available builds, retrieves published release packages, and arranges the local files needed during setup before opening the application.

The workflow is intended for photo restoration and image retouching, with support for tasks such as removing scratches and reconstructing color. Multiple images can be processed through batch operations, and on-screen progress indicates the current setup or update activity.

## Troubleshooting Guide

### The loader will not open

Make sure the downloaded file is a Windows build, then run it again from a local directory. If Windows prevents execution, inspect the file properties and respond to the operating system's security prompts before retrying.

### The update check returns no result

Review the channel currently selected and verify that the system can connect to the release location. If you already have a package on the computer, the manual channel can be used instead.

### A download fails or pauses indefinitely

Check the network connection and run the update check again. Before retrying, remove or move any incomplete download stored locally.

### I cannot find the setup files

Use a separate working directory when starting the loader. Release packages and other setup files will then remain together in one location.

### Progress does not appear to change

Check the progress display to see whether the utility is checking, downloading, or preparing files. When no progress is visible, exit the loader and start the launch sequence again.

### Batch processing cannot be used

Verify that the installed build supports the workflow you want and that the selected images can be accessed by the current Windows account.

## Frequently Asked Questions

### Will the loader check for updates on its own?

A build check is performed when you begin the update workflow. The channel you choose controls which release path the loader examines.

### Where does the loader save downloaded content?

The loader places downloaded and setup-related content in the local working directory it uses. Select a dedicated folder if you want all of these files grouped together.

### Is it possible to install a particular release?

Yes. Select the manual update channel and use the required release package instead of following the stable or latest path.

### Can an earlier build be restored?

An earlier build can be used through the manual update workflow if its package is available. Have that package stored locally before starting setup.

### Does the utility show operation status?

Yes. The loader displays setup and update progress while it checks for builds, downloads packages, and prepares files.

### Can several images be processed together?

Yes. The workflow supports batch processing for multiple images.

### What operating systems can run the loader?

Windows is the target platform identified for this product. Actual compatibility can vary with the selected build and the configuration of the local system.

### Is more than one language supported?

Yes. The AKVIS Retoucher workflow includes multilingual support.
